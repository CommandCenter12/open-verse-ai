Answers you can check.

Open Verse Ai is an open-source Q&A API for mechatronics and stock-analysis questions. Answers from this repo's documents cite their source. Arithmetic is computed exactly. Anything else gets a clearly labelled, uncited answer from a Llama model.

Docs first

mode: "docs" answers are sentences from knowledge/*.md, linked to the exact section.

Exact math

mode: "math": 1+1 is computed, not generated.

Labelled AI

mode: "general" answers come from Llama, are marked unverified, and can be turned off with sources_only.

Quick start

curl -X POST "$API/v1/ask" \
  -H "Authorization: Bearer $OVA_KEY" \
  -H "Content-Type: application/json" \
  -d '{"question":"How do I tune a PID controller?"}'

Example topics: PID tuning, stepper microstepping, encoder resolution, ADC sampling, P/E ratio, RSI, Sharpe ratio, position sizing.
