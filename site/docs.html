API reference

Base URL: . All requests and responses use JSON.

Authentication

Send your key as Authorization: Bearer ova_… (preferred) or X-API-Key: ova_…. The server stores only a SHA-256 hash, so a lost key can't be recovered. Create a new one instead.

Answer modes

noneNothing appliesanswered: false, plus general_unavailable with the reason

Owner keys (created only with a local script, never via the API) also get the owner's profile and up to 3 relevant excerpts from their own chats, Drive, sent email, Keep and Calendar as background for general answers, listed in memory_sources (M1–M3). Send "use_memory": false to skip it. Public keys never see memory.

General answers are limited to 50 per key per UTC day. Questions about this API (keys, endpoints, limits) are never sent to the model, so it can't invent features.

Limits

20 asks per minute and 500 per UTC day per key (defaults). Responses carry X-RateLimit-Limit and X-RateLimit-Remaining. A 429 includes Retry-After in seconds.

Adding knowledge

Add a Markdown file to knowledge/. Each ##/### section becomes one searchable chunk. Optional front matter: title, domain, disclaimer. Then run npm run deploy in worker/ (it rebuilds the index first).
