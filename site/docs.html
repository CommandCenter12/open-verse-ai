API reference

Base URL: . All requests and responses use JSON.

Authentication

Send your key as Authorization: Bearer ova_… (preferred) or X-API-Key: ova_…. The server stores only a SHA-256 hash, so a lost key can't be recovered. Create a new one instead.

Endpoints

Method & pathAuthPurpose
GET /v1/healthNoService status and index size.
POST /v1/keysNoCreate a key. Body: {"label":"optional"}. Key returned once. 3 per network per day.
GET /v1/meYesKey prefix, label and current usage.
POST /v1/askYesAsk a question. Body: {"question":"…","top_k":3}.
DELETE /v1/keys/currentYesRevoke the key used for this request.

When nothing in the knowledge base matches well enough, you get "answered": false, "answer": null, empty sources, and nearest_topics to help you rephrase.

Limits

20 asks per minute and 500 per UTC day per key (defaults). Responses carry X-RateLimit-Limit and X-RateLimit-Remaining. A 429 includes Retry-After in seconds.

Adding knowledge

Add a Markdown file to knowledge/. Each ##/### section becomes one searchable chunk. Optional front matter: title, domain, disclaimer. Then run npm run deploy in worker/ (it rebuilds the index first).
